什么是 PBL？

Project-Based Learning
PBL（Project-Based Learning）项目式学习，是让学生围绕一个真实世界的问题，用几周甚至一个学期去深入探究、动手解决，最终产出一份真实可用作品的学习方式。它和传统课堂最大的区别，是把学习从课本里搬进真实生活。
真实问题

不是编的题

任务来自真实校园、社区、古镇，孩子面对的是真问题。

跨学科

知识被串起来

数学、科学、语文、经济、艺术在一个项目里被真正调用。

学生主导

老师是引导者

孩子自己调研、提问、分工、试错、调整，老师搭脚手架。

真实成果

作品能看见

最终产出一间店、一块地、一套方案、一场路演，被使用被评价。

我们不是在教会做题的孩子，而是在培养能做事的孩子。

PBL 案例 · 校园零浪费小店

Zero-Waste Corner · A Real Pilot
和鸣学院 · G7–8 真实项目 · 边上课边真实运营

校园零浪费小店 / 二手循环站

The Zero-Waste Corner · A Campus Circular Economy Pilot
学科：经济 / 商科 / 语文 ｜ 队伍：G7–8 混龄 5 人 ｜ 客户：全校师生 + 后勤 / 校长办（审批方）
驱动问题：循环经济在我们学校到底能不能跑通？——不猜，用一次真实试运营来回答。
为什么说它是"边上课边真实运营"？这个项目从第 3 周起就真的开店：孩子不是"模拟"开小店，而是真正面对全校同学营业、真正记台账、真正为"要不要继续开下去"给出证据。台账纪律是生命线——每笔交易都得逐笔可查。

① 孩子要达成的成功标准

  • ≥30 份普查问卷：摸清校园闲置物品的品类与数量
  • 两轮真实试运营：W3 完成，每轮 ≥2 个营业窗口，台账逐笔可查，实现"边上课边真实运营"
  • 数据驱动的复盘：周转率、参与率、问题与改进的因果链
  • 给出常态化建议：用证据说清"是否值得常态化"，允许答案是"不值得"

② 四周怎么推进（时间轴 · 每周落到了具体课）

W1
W1 · 8/31–9/4学科：经济 · 语文
启动与假设、普查问卷与案例对标
  • L1 启动 + 假设：读懂任务；每人写下 3 个"如果……，则……"的可检验假设；完成分工与队规。→ 假设卡+分工表+队规
  • L2 普查设计：设计校园闲置普查问卷（书籍/文具/体育/电子/衣物等），定观察点（教室垃圾桶/楼道/失物招领处），并分工研究 3 个对标案例。→ 问卷 v2 + 观察分工 + 案例卡
  • M1 · 9/4：回收 ≥30 份问卷，完成观察与案例研究，数据官做出统计图表。→ 问卷 30+ / 观察 3 点位 / 案例卡 3 张 / 图表 3 张
W2
W2 · 9/7–9/11学科：经济 · 商科 · 语文
需求分析、模式决策、SOP 与报批函
  • L3 需求分析与模式决策：复盘问卷数据，画出"供给 vs 需求"两栏表；在"捐赠交换 / 积分 / 低价寄售"三种模式下打分决策，选出一种。→ 供需表 + 决策矩阵 + 模式选定
  • L4 运营方案 + 报批：产出完整运营方案（SOP 流程 + 台账 + 定价 + 宣传 + 卫生），当堂填写报批申请函递交给后勤/校长办，并定场地与宣传文案。→ 方案一页纸 + 申请函（9/11 前递交）
  • M2 · 9/11：运营一页纸（模式/SOP/定价/场地）+ 申请函已交 + 宣传文案初稿 + 物资清单（店招/价签/消毒用品/零钱盒）。→ 方案+报批
W3
W3 · 9/14–9/18学科：商科 · 经济
真实运营、台账纪律、问题归因
  • L5 物料与软启动：物料到位；向本班和教师办公室发"闲置征集令"；做一次全流程"桌面演练"（捐赠→登记→消毒→上架→成交→记账）；排好营业窗口班表。→ 首批物品 ≥15 件 + 排班表 + 演练记录
  • L6 第一轮试运营 + 复盘：开第一个营业窗口（大课间/午休，10 分钟，2 人一班），教师旁观不打扰；即时记下进/出/成交/围观/问题，填营业日报，追问"哪里卡住了"到流程节点，形成问题清单与改进方案。→ 首轮台账 + 营业日报 1 + 改进清单
  • M3 · 9/18：≥2 个营业窗口、逐笔台账、营业日报、改进清单。→ 第一轮运营
W4
W4 · 9/21–9/24学科：经济 · 商科 · 语文
数据对比、报告写作、双语路演与问答
  • L7 第二轮试运营 + 数据汇总：落实改进后二次运营；学会算周转率、参与率；把两轮数据做成对比表（窗口数/上架/成交/周转/参与/收入），搭报告框架。→ 第二轮数据 + 两轮对比表 + 报告目录
  • L8 报告定稿 + 彩排：核对数据、图表、因果链、双语摘要与"是否常态化"建议；做 5+3 分钟双语路演彩排与问答演练；准备 Showcase 现场迷你循环站（带 10 件物品现场交换 + 台账展示）。→ 报告 v2 + 路演录像 + 现场站方案
  • M4 · 9/23：第二轮数据、两轮对比表、复盘报告定稿（含双语摘要）、现场站物资、值班表。→ 终稿 + Showcase（9/24 现场）

③ 这个项目用到了哪些学科与课堂能力

经济

循环经济、资源配置评价重点：用数据复盘质量评估：能不能用真实数据推动运营决策

商科

进销存、定价、运营评价重点：以台账与流程规范为评价重点：逐笔可查、日清日结

语文

宣传文案、报告写作评价重点：用协作过程记录看孩子如何把发现讲清楚、写明白

综合

跨学科统筹评价重点：看改进迭代的证据：两轮差异是否一一对应到原因
